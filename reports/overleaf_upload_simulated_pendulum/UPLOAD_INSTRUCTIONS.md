# Overleaf Upload Instructions

Upload the contents of this folder to Overleaf.

Required files:

```text
report.tex
report-template.cls
references.bib
generated/simulated_pendulum/tables.tex
generated/simulated_pendulum/figures.tex
generated/simulated_pendulum/figures/*.png
```

Do not upload these from the original template folder:

```text
report.pdf
Makefile
figures/experiment.jpg
generated/toy_physics/
.DS_Store
```

In Overleaf, set `report.tex` as the main file.
